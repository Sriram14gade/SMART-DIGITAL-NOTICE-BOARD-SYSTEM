Project Title: Smart Digital Notice Board System
Problem Statement:
Colleges currently print notices on paper and post them on physical notice boards. This wastes paper, delays urgent updates (like exam times or holidays), and causes students to miss crucial information.
Key Features:
• Real-time digital notice posting (Exams, Events, Academics)
• Role-based access for Admin/Faculty and Students
• Mobile-responsive and modern design
• Smart alerts for attendance and exam schedules
Technologies Used:
• Frontend: React.js, Tailwind CSS, Lucide Icons
• Backend: Node.js, Express.js
• Database: MongoDB
